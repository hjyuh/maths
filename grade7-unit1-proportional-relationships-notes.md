## Lesson 1: Understanding Ratios

### What is a Ratio?

A **ratio** is a comparison of two quantities. Ratios can be written in three ways:
- Using the word "to": 3 to 5
- Using a colon: 3:5
- As a fraction: 3/5

**Key Concept:** Ratios show how quantities relate to each other but don't necessarily show the actual amounts.

**Example 1:** In a class, the ratio of boys to girls is 3:4
```
This means:
- For every 3 boys, there are 4 girls
- This could represent 3 boys and 4 girls (7 students)
- Or 6 boys and 8 girls (14 students)
- Or 12 boys and 16 girls (28 students)
- The ratio stays constant: 3:4
```

**Example 2:** A recipe uses 2 cups of flour for every 3 eggs
```
Ratio of flour to eggs = 2:3
For 4 cups of flour, you would need 6 eggs
For 6 cups of flour, you would need 9 eggs
```

### Equivalent Ratios

**Equivalent ratios** represent the same comparison. They are found by multiplying or dividing both terms by the same number.

**Example:**
```
4:6 is equivalent to 2:3 (divide both by 2)
4:6 is equivalent to 8:12 (multiply both by 2)
All represent the same proportional relationship
```

## Lesson 2: Rates and Unit Rates

### Understanding Rates

A **rate** is a ratio that compares two quantities with different units.

**Examples:**
- 60 miles per 2 hours (speed)
- $3.99 per pound (price)
- 150 words in 3 minutes (typing speed)

### Unit Rates

A **unit rate** is a rate where the second quantity is 1 unit.

**To find a unit rate:** Divide the first quantity by the second quantity

**Example 1:** Find the unit rate for 120 miles in 3 hours
```
120 miles ÷ 3 hours = 40 miles per 1 hour
Unit rate: 40 miles per hour (mph)
```

**Example 2:** A 12-pack of soda costs $4.80. Find the unit price.
```
$4.80 ÷ 12 cans = $0.40 per can
Unit price: $0.40 per can
```

**Example 3:** Comparing unit rates
```
Store A: 3 pounds for $7.50
Store B: 5 pounds for $11.75

Store A unit rate: $7.50 ÷ 3 = $2.50 per pound
Store B unit rate: $11.75 ÷ 5 = $2.35 per pound

Store B has the better deal!
```

## Lesson 3: Proportional Relationships

### What is a Proportional Relationship?

Two quantities have a **proportional relationship** if they maintain a constant ratio or unit rate.

**Key Properties:**
1. The ratio y/x is constant (called the constant of proportionality, k)
2. The equation is y = kx (where k is the constant)
3. The graph is a straight line through the origin (0,0)
4. The table shows equivalent ratios

**Example:** y is proportional to x with constant k = 3
```
Equation: y = 3x

Table:
x | y
--|--
0 | 0
1 | 3
2 | 6
3 | 9
4 | 12

Notice: y/x = 3 for all values
```

### Identifying Proportional Relationships from Tables

**Method:** Check if the ratio y/x is constant

**Example 1:** Is this proportional?
```
x | y
--|--
2 | 6
4 | 12
6 | 18

Check: 6/2 = 3, 12/4 = 3, 18/6 = 3
Yes! The constant of proportionality is 3
```

**Example 2:** Is this proportional?
```
x | y
--|--
1 | 5
2 | 8
3 | 11

Check: 5/1 = 5, 8/2 = 4, 11/3 ≈ 3.67
No! The ratios are not constant
```

### Identifying Proportional Relationships from Graphs

**A proportional relationship:**
- Is a straight line
- Passes through the origin (0,0)
- Has slope equal to k (the constant of proportionality)

**Not proportional if:**
- The line doesn't pass through the origin
- The graph is not a straight line

## Lesson 4: Writing Equations for Proportional Relationships

### The Proportional Relationship Equation

**General form:** y = kx

Where:
- k = constant of proportionality
- x = independent variable
- y = dependent variable

**Example 1:** Write an equation
```
A car travels 65 miles per hour.
Let h = hours traveled
Let d = distance traveled

k = 65 (the constant rate)
Equation: d = 65h
```

**Example 2:** From a table
```
x | y
--|--
3 | 15
5 | 25
7 | 35

Find k: k = y/x = 15/3 = 5
Equation: y = 5x
```

## Lesson 5: Solving Proportions

### What is a Proportion?

A **proportion** is an equation stating that two ratios are equal.

**Form:** a/b = c/d

### Cross-Multiplication Method

To solve proportions, use cross-multiplication:
If a/b = c/d, then ad = bc

**Example 1:** Solve for x: x/5 = 6/15
```
Cross multiply: 15x = 5(6)
15x = 30
x = 2
```

**Example 2:** Solve for n: 3/4 = n/20
```
Cross multiply: 4n = 3(20)
4n = 60
n = 15
```

**Example 3:** Real-world application
```
If 3 shirts cost $45, how much do 7 shirts cost?

Set up proportion: 3/45 = 7/x
Cross multiply: 3x = 45(7)
3x = 315
x = 105

Answer: $105
```

## Lesson 6: Circle Circumference

### Circumference Formula

**Circumference** is the distance around a circle.

**Formula:** C = πd or C = 2πr

Where:
- C = circumference
- d = diameter
- r = radius
- π ≈ 3.14 or 22/7

**Key Relationship:** diameter = 2 × radius, so d = 2r

**Example 1:** Find the circumference (diameter = 10 cm)
```
C = πd
C = 3.14 × 10
C = 31.4 cm
```

**Example 2:** Find the circumference (radius = 7 inches)
```
C = 2πr
C = 2 × 3.14 × 7
C = 43.96 inches
```

**Example 3:** Find the diameter when C = 62.8 feet
```
C = πd
62.8 = 3.14 × d
d = 62.8 ÷ 3.14
d = 20 feet
```

## Lesson 7: Circle Area

### Area Formula

**Area** is the space inside a circle.

**Formula:** A = πr²

Where:
- A = area
- r = radius
- π ≈ 3.14

**Example 1:** Find the area (radius = 5 cm)
```
A = πr²
A = 3.14 × 5²
A = 3.14 × 25
A = 78.5 cm²
```

**Example 2:** Find the area (diameter = 12 inches)
```
First find radius: r = 12 ÷ 2 = 6 inches
A = πr²
A = 3.14 × 6²
A = 3.14 × 36
A = 113.04 in²
```

**Example 3:** Find the radius when A = 154 cm²
```
A = πr²
154 = 3.14 × r²
r² = 154 ÷ 3.14
r² = 49
r = 7 cm
```

## Lesson 8: Multi-Step Ratio and Percent Problems

### Solving Complex Ratio Problems

**Example 1:** Scale models
```
A model car has a scale of 1:24. If the model is 6 inches long, how long is the actual car?

Set up proportion: 1/24 = 6/x
Cross multiply: x = 24 × 6
x = 144 inches = 12 feet
```

**Example 2:** Recipe scaling
```
A recipe for 4 people uses 3 cups of flour. How much flour is needed for 14 people?

Set up proportion: 4/3 = 14/x
Cross multiply: 4x = 42
x = 10.5 cups
```

### Percent as a Ratio

**Remember:** Percent means "per hundred"
- 25% = 25/100 = 0.25
- 50% = 50/100 = 0.50

**Example:** Find 15% of 80
```
Method 1: 0.15 × 80 = 12
Method 2: 15/100 = x/80
         100x = 1200
         x = 12
```

## Key Vocabulary

- **Ratio:** A comparison of two quantities
- **Rate:** A ratio comparing quantities with different units
- **Unit Rate:** A rate with a denominator of 1
- **Proportional Relationship:** Two quantities that maintain a constant ratio
- **Constant of Proportionality (k):** The constant ratio in y = kx
- **Proportion:** An equation stating two ratios are equal
- **Circle:** A set of points equidistant from a center point
- **Radius:** Distance from center to edge of circle
- **Diameter:** Distance across circle through center
- **Circumference:** Distance around a circle
- **Pi (π):** The ratio of circumference to diameter (≈ 3.14)

---

## Practice Tips

1. Always label units in rates and ratios
2. Check if (0,0) is on the graph to determine proportionality
3. Use cross-multiplication to solve proportions
4. Remember: diameter = 2 × radius
5. When finding area, make sure to square the radius
6. Use π ≈ 3.14 unless instructed otherwise
7. Set up proportions carefully - keep corresponding values in the same position
8. Double-check your unit conversions
9. Draw diagrams for circle problems to visualize radius and diameter
10. Verify proportional relationships by checking multiple ratios
