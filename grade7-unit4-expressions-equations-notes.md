## Lesson 1: Simplifying Algebraic Expressions

### Combining Like Terms

**Like terms** have the same variables raised to the same powers.

**Examples of like terms:**
- 3x and 5x (both have variable x)
- -2y² and 7y² (both have y²)
- 4ab and -ab (both have ab)

**Not like terms:**
- 3x and 3x² (different powers)
- 5y and 5z (different variables)
- 4 and 4x (one has variable, one doesn't)

**To simplify:** Add or subtract the coefficients of like terms

**Example 1:** 5x + 3x
```
= (5 + 3)x
= 8x
```

**Example 2:** 7y - 2y + 4y
```
= (7 - 2 + 4)y
= 9y
```

**Example 3:** 3x + 5y - x + 2y
```
Combine x terms: 3x - x = 2x
Combine y terms: 5y + 2y = 7y
Answer: 2x + 7y
```

**Example 4:** 4a² + 3a - 2a² + 5a
```
Combine a² terms: 4a² - 2a² = 2a²
Combine a terms: 3a + 5a = 8a
Answer: 2a² + 8a
```

## Lesson 2: The Distributive Property

### Using the Distributive Property

**Property:** a(b + c) = ab + ac

**To expand:** Multiply the term outside parentheses by each term inside

**Example 1:** 3(x + 4)
```
= 3·x + 3·4
= 3x + 12
```

**Example 2:** -2(3y - 5)
```
= -2·3y + (-2)·(-5)
= -6y + 10
```

**Example 3:** 5(2a + 3b - 4)
```
= 5·2a + 5·3b + 5·(-4)
= 10a + 15b - 20
```

### Factoring with the Distributive Property

**To factor:** Find the GCF and write as a product

**Example 1:** 6x + 9
```
GCF = 3
= 3(2x + 3)
```

**Example 2:** 4y - 12
```
GCF = 4
= 4(y - 3)
```

**Example 3:** 15a + 25b
```
GCF = 5
= 5(3a + 5b)
```

## Lesson 3: Simplifying Complex Expressions

### Multi-Step Simplification

**Strategy:**
1. Use distributive property to remove parentheses
2. Combine like terms

**Example 1:** 3(x + 2) + 4x
```
Step 1: Distribute: 3x + 6 + 4x
Step 2: Combine: 7x + 6
```

**Example 2:** 2(3y - 1) - 5(y + 2)
```
Step 1: Distribute: 6y - 2 - 5y - 10
Step 2: Combine: y - 12
```

**Example 3:** 4(2x + 3) - 3(x - 1) + 5
```
Distribute: 8x + 12 - 3x + 3 + 5
Combine: 5x + 20
```

**Example 4:** ½(6x + 4) + 2(x - 3)
```
Distribute: 3x + 2 + 2x - 6
Combine: 5x - 4
```

## Lesson 4: Solving One-Step Equations

### Addition and Subtraction Equations

**Goal:** Isolate the variable using inverse operations

**Example 1:** x + 7 = 15
```
Subtract 7 from both sides:
x + 7 - 7 = 15 - 7
x = 8
```

**Example 2:** y - 5 = 12
```
Add 5 to both sides:
y - 5 + 5 = 12 + 5
y = 17
```

**Example 3:** -3 + n = 10
```
Add 3 to both sides:
n = 13
```

### Multiplication and Division Equations

**Example 1:** 4x = 28
```
Divide both sides by 4:
4x ÷ 4 = 28 ÷ 4
x = 7
```

**Example 2:** y/3 = 9
```
Multiply both sides by 3:
y = 27
```

**Example 3:** -5n = 35
```
Divide both sides by -5:
n = -7
```

## Lesson 5: Solving Two-Step Equations

### Strategy: Undo in Reverse Order (PEMDAS backwards)

**Steps:**
1. Add or subtract first (undo addition/subtraction)
2. Multiply or divide second (undo multiplication/division)

**Example 1:** 2x + 5 = 13
```
Step 1: Subtract 5 from both sides
2x = 8
Step 2: Divide both sides by 2
x = 4
```

**Example 2:** 3y - 7 = 14
```
Step 1: Add 7 to both sides
3y = 21
Step 2: Divide both sides by 3
y = 7
```

**Example 3:** x/4 + 6 = 10
```
Step 1: Subtract 6 from both sides
x/4 = 4
Step 2: Multiply both sides by 4
x = 16
```

**Example 4:** -2n + 3 = 15
```
Step 1: Subtract 3 from both sides
-2n = 12
Step 2: Divide both sides by -2
n = -6
```

## Lesson 6: Solving Multi-Step Equations

### Equations with Variables on Both Sides

**Strategy:** Move all variables to one side, constants to the other

**Example 1:** 5x - 3 = 2x + 9
```
Step 1: Subtract 2x from both sides
3x - 3 = 9
Step 2: Add 3 to both sides
3x = 12
Step 3: Divide by 3
x = 4
```

**Example 2:** 4y + 7 = y - 5
```
Subtract y from both sides: 3y + 7 = -5
Subtract 7 from both sides: 3y = -12
Divide by 3: y = -4
```

### Equations with Parentheses

**Strategy:** Use distributive property first, then solve

**Example 1:** 2(x + 3) = 14
```
Distribute: 2x + 6 = 14
Subtract 6: 2x = 8
Divide by 2: x = 4
```

**Example 2:** 3(2y - 1) + 5 = 20
```
Distribute: 6y - 3 + 5 = 20
Combine: 6y + 2 = 20
Subtract 2: 6y = 18
Divide by 6: y = 3
```

**Example 3:** 4(x - 2) = 2(x + 3)
```
Distribute: 4x - 8 = 2x + 6
Subtract 2x: 2x - 8 = 6
Add 8: 2x = 14
Divide by 2: x = 7
```

## Lesson 7: Writing Equations from Word Problems

### Translating Words to Equations

**Key phrases:**

| Words | Symbol |
|-------|--------|
| sum, plus, more than, increased by | + |
| difference, minus, less than, decreased by | - |
| product, times, multiplied by | × |
| quotient, divided by | ÷ |
| is, equals, results in | = |

**Example 1:** Simple translation
```
"Five more than a number is 18"
Let n = the number
n + 5 = 18
```

**Example 2:** Two-step problem
```
"Three times a number, decreased by 7, is 20"
Let x = the number
3x - 7 = 20
```

**Example 3:** Real-world context
```
"A taxi charges $3 plus $2 per mile. The total charge was $17. How many miles?"
Let m = miles
2m + 3 = 17
```

## Lesson 8: Understanding Inequalities

### Inequality Symbols

- **>** greater than
- **<** less than
- **≥** greater than or equal to
- **≤** less than or equal to
- **≠** not equal to

### Graphing Inequalities on a Number Line

**Open circle:** < or > (does not include the number)
**Closed circle:** ≤ or ≥ (includes the number)

**Example 1:** x > 3
```
Open circle at 3, shade to the right
    ○━━━━━━→
    3
```

**Example 2:** y ≤ -2
```
Closed circle at -2, shade to the left
←━━━━━●
     -2
```

**Example 3:** n ≥ 0
```
Closed circle at 0, shade to the right
    ●━━━━━→
    0
```

## Lesson 9: Solving One-Step Inequalities

### Addition and Subtraction

**Rule:** Same as equations - use inverse operations

**Example 1:** x + 5 > 12
```
Subtract 5 from both sides:
x > 7
```

**Example 2:** y - 3 ≤ 8
```
Add 3 to both sides:
y ≤ 11
```

### Multiplication and Division

**Important Rule:** When multiplying or dividing by a **negative number**, flip the inequality sign!

**Example 1:** 3x < 15
```
Divide both sides by 3:
x < 5
```

**Example 2:** -2y > 10
```
Divide both sides by -2 (FLIP the sign):
y < -5
```

**Example 3:** x/4 ≥ 2
```
Multiply both sides by 4:
x ≥ 8
```

**Example 4:** -n ≤ 6
```
Divide by -1 (FLIP the sign):
n ≥ -6
```

## Lesson 10: Solving Multi-Step Inequalities

### Strategy: Same as Equations

**Follow the same steps as multi-step equations**
**Remember:** Flip the sign if multiplying/dividing by negative!

**Example 1:** 2x + 3 < 11
```
Subtract 3: 2x < 8
Divide by 2: x < 4
```

**Example 2:** -3y - 5 ≥ 10
```
Add 5: -3y ≥ 15
Divide by -3 (FLIP): y ≤ -5
```

**Example 3:** 4(x - 2) > 12
```
Distribute: 4x - 8 > 12
Add 8: 4x > 20
Divide by 4: x > 5
```

**Example 4:** 5 - 2n ≤ 13
```
Subtract 5: -2n ≤ 8
Divide by -2 (FLIP): n ≥ -4
```

## Lesson 11: Writing and Solving Inequality Word Problems

### Common Inequality Phrases

- "at least" → ≥
- "at most" → ≤
- "more than" → >
- "less than" → <
- "no more than" → ≤
- "no less than" → ≥

**Example 1:** Minimum requirement
```
"You must be at least 48 inches tall to ride"
Let h = height
h ≥ 48
```

**Example 2:** Maximum capacity
```
"The elevator can hold at most 2000 pounds"
Let w = weight
w ≤ 2000
```

**Example 3:** Budget problem
```
"You have $50. After buying a $12 shirt, you want to buy books for $8 each. How many books can you buy?"
Let b = number of books
12 + 8b ≤ 50
8b ≤ 38
b ≤ 4.75
Answer: At most 4 books (can't buy partial books)
```

## Lesson 12: Equivalent Expressions

### Identifying Equivalent Expressions

**Equivalent expressions** have the same value for all values of the variable.

**Example 1:** Are 2(x + 3) and 2x + 6 equivalent?
```
Expand: 2(x + 3) = 2x + 6
Yes, they are equivalent!
```

**Example 2:** Are 3x + 5 and 5 + 3x equivalent?
```
By commutative property: Yes!
```

**Example 3:** Are 4(2x - 1) and 8x - 1 equivalent?
```
Expand: 4(2x - 1) = 8x - 4
No! (8x - 4 ≠ 8x - 1)
```

## Key Vocabulary

- **Expression:** A mathematical phrase with numbers, variables, and operations
- **Equation:** A statement that two expressions are equal (uses =)
- **Inequality:** A statement comparing two expressions (uses <, >, ≤, ≥)
- **Like Terms:** Terms with the same variables raised to the same powers
- **Coefficient:** The numerical factor of a term
- **Constant:** A term without a variable
- **Variable:** A letter representing an unknown value
- **Solution:** The value(s) that make an equation or inequality true
- **Inverse Operation:** The opposite operation (addition ↔ subtraction, multiplication ↔ division)
- **Distributive Property:** a(b + c) = ab + ac
- **Equivalent Expressions:** Expressions that have the same value for all variable values

## Practice Tips

1. Always combine like terms when simplifying
2. Use distributive property to remove parentheses
3. Work equations backward (undo operations in reverse order)
4. Remember to flip inequality signs when multiplying/dividing by negatives
5. Check your solutions by substituting back into original equation
6. Draw number lines to visualize inequalities
7. Keep equations balanced (what you do to one side, do to the other)
8. Write word problems as equations step by step
9. Identify what the variable represents before writing equations
10. Practice recognizing equivalent expressions
