## Lesson 1: Volume of Rectangular Prisms

### Understanding Volume

**Volume** measures the amount of space inside a three-dimensional figure, measured in cubic units.

**Key Formula:** V = length × width × height (V = lwh)
**Alternative Formula:** V = Base Area × height (V = Bh)

### Volume with Whole Number Dimensions

**Example 1:**
```
Length = 5 cm, Width = 3 cm, Height = 4 cm
V = 5 × 3 × 4 = 60 cm³
```

### Volume with Fractional Dimensions

The formula works the same way with fractions!

**Example 2:**
```
Length = 4½ cm, Width = 2 cm, Height = 3 cm
V = 4½ × 2 × 3
V = 9/2 × 2 × 3
V = 27 cm³
```

**Example 3:**
```
Length = 2.5 in, Width = 1.5 in, Height = 4 in
V = 2.5 × 1.5 × 4
V = 3.75 × 4
V = 15 in³
```

### Using the Base Area Formula

**Step 1:** Find the area of the base (B)
**Step 2:** Multiply by the height (h)

**Example:**
```
Rectangular base: 5 cm × 3 cm = 15 cm²
Height: 4 cm
V = Bh = 15 × 4 = 60 cm³
```

## Lesson 2: Dividing Multi-Digit Numbers

### Long Division Algorithm

**Steps for division:**
1. **D**ivide
2. **M**ultiply
3. **S**ubtract
4. **B**ring down
5. **R**epeat

**Example: 456 ÷ 12**
```
     38
   ----
12)456
   36↓
   ---
    96
    96
   ---
     0
```
Answer: 38

### Division with Remainders

**Example: 523 ÷ 15**
```
     34 R13
   ------
15)523
   45↓
   ---
    73
    60
   ---
    13
```
Answer: 34 R13 or 34¹³⁄₁₅

### Checking Division

**Method:** Multiply quotient × divisor + remainder = dividend
```
34 × 15 + 13 = 510 + 13 = 523 ✓
```

## Lesson 3: Operations with Multi-Digit Decimals

### Adding Decimals

**Key Rule:** Line up the decimal points!

**Example:**
```
  23.45
+ 18.7
-------
  42.15
```

### Subtracting Decimals

**Example:**
```
  45.6
- 12.38
-------
  33.22
```

### Multiplying Decimals

**Steps:**
1. Multiply as if there were no decimals
2. Count total decimal places in both factors
3. Place decimal point in the product

**Example: 3.4 × 2.5**
```
  3.4    (1 decimal place)
× 2.5    (1 decimal place)
-----
  170
+ 680
-----
 8.50   (2 decimal places total)
= 8.5
```

### Dividing Decimals

**Key Rule:** Make the divisor a whole number by moving the decimal point!

**Example: 12.6 ÷ 0.3**
```
Move decimal one place in both numbers:
126 ÷ 3 = 42
```

**Example: 4.56 ÷ 1.2**
```
Move decimal one place in both:
45.6 ÷ 12

     3.8
   -----
12)45.6
   36↓
   ---
    9.6
    9.6
   ---
     0
```
Answer: 3.8

## Lesson 5: Dividing Fractions by Fractions

### The Algorithm: Multiply by the Reciprocal

**Rule:** To divide by a fraction, multiply by its reciprocal

**Reciprocal:** Flip the numerator and denominator
- Reciprocal of ²⁄₃ is ³⁄₂
- Reciprocal of ⁵⁄₇ is ⁷⁄₅

### Examples

**Example 1:** ½ ÷ ¼
```
½ ÷ ¼ = ½ × ⁴⁄₁
     = ⁴⁄₂
     = 2
```

**Example 2:** ³⁄₄ ÷ ²⁄₃
```
³⁄₄ ÷ ²⁄₃ = ³⁄₄ × ³⁄₂
         = ⁹⁄₈
         = 1¹⁄₈
```

**Example 3:** 2 ÷ ³⁄₅
```
2 ÷ ³⁄₅ = ²⁄₁ × ⁵⁄₃
       = ¹⁰⁄₃
       = 3¹⁄₃
```

### Word Problems with Fraction Division

**Example:** A ribbon is ⁵⁄₆ yard long. How many ¹⁄₆-yard pieces can be cut from it?
```
⁵⁄₆ ÷ ¹⁄₆ = ⁵⁄₆ × ⁶⁄₁ = ³⁰⁄₆ = 5 pieces
```

## Lesson 6: Using Models for Fraction Division

### Area Models

**Example:** ²⁄₃ ÷ ¹⁄₆
```
Draw ²⁄₃ of a rectangle
Divide into sixths
Count how many sixths: 4 sixths
Answer: 4
```

### Number Line Models

**Example:** 1 ÷ ¼
```
|----|----|----|----|
0   ¼   ½   ¾   1
```

## Key Vocabulary

- **Volume:** Amount of space inside a 3D figure (cubic units)
- **Cubic units:** Units for measuring volume (cm³, in³, ft³)
- **Dividend:** The number being divided
- **Divisor:** The number dividing
- **Quotient:** The answer to a division problem
- **Remainder:** Amount left over after division
- **Decimal point:** Separates whole numbers from fractional parts
- **Reciprocal:** The multiplicative inverse (flip of a fraction)
- **Algorithm:** A step-by-step procedure for calculations

---

## Practice Tips

1. For volume, always use cubic units (cm³, not cm²)
2. When adding/subtracting decimals, line up decimal points
3. When multiplying decimals, count total decimal places
4. For fraction division: multiply by the reciprocal
5. Draw models to understand fraction division
6. Check division by multiplying: quotient × divisor = dividend
