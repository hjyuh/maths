## Part 5: Properties

**17.** 3 log₂(x) + 2 log₂(y) - log₂(z)

Solution:
```
log₂(x³y²/z) = log₂(x³y²) - log₂(z)      (quotient property)
              = log₂(x³) + log₂(y²) - log₂(z)  (product property)
              = 3 log₂(x) + 2 log₂(y) - log₂(z)  (power property)
```

**18.** ln(x³z/y²)

Solution:
```
3 ln(x) - 2 ln(y) + ln(z) = ln(x³) - ln(y²) + ln(z)  (power property)
                           = ln(x³) + ln(z) - ln(y²)  (rearrange)
                           = ln(x³z) - ln(y²)         (product property)
                           = ln(x³z/y²)               (quotient property)
```

## Part 6: Exponential Equations

**19.** x = 5/2 or x = 2.5

Solution:
```
3²ˣ⁻¹ = 81
3²ˣ⁻¹ = 3⁴       (rewrite 81 as 3⁴)
2x - 1 = 4       (set exponents equal)
2x = 5
x = 5/2 or 2.5
```

**20.** x ≈ 3.585

Solution:
```
5 · 2ˣ = 60
2ˣ = 12          (divide by 5)
log(2ˣ) = log(12)  (take log of both sides)
x log(2) = log(12)  (power property)
x = log(12)/log(2)
x ≈ 3.585
```

Alternative using ln:
```
x = ln(12)/ln(2) ≈ 3.585
```

## Part 7: Logarithmic Equations

**21.** x = 64

Solution:
```
log₄(x) = 3
4³ = x           (convert to exponential form)
x = 64
```

**22.** x = 20

Solution:
```
log(x) + log(5) = 2
log(5x) = 2           (product property)
10² = 5x              (exponential form)
100 = 5x
x = 20
```

Verify: log(20) + log(5) = log(100) = 2 ✓

**BONUS 1:** 25 grams

```
Half-life = 12 years

A = A₀(1/2)ⁿ
  = 200(1/2)³
  = 200 · 1/8

```

**BONUS 2:** t ≈ 17.329 years

Solution:
```
A = Peʳᵗ
3000 = 1500e⁰·⁰⁴ᵗ
2 = e⁰·⁰⁴ᵗ           (divide by 1500)
ln(2) = 0.04t        (take natural log)
t = ln(2)/0.04
t ≈ 0.6931.../0.04
t ≈ 17.329 years
```
