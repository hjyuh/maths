## Part 3: Coordinate Proofs (12 points)

**7.** (4 points)
AB = √[(5-1)² + (6-2)²] = √[16+16] = √32 = 4√2
BC = √[(5-5)² + (-2-6)²] = √[0+64] = 8
AC = √[(5-1)² + (-2-2)²] = √[16+16] = √32 = 4√2

Since AB = AC = 4√2, **△ABC is isosceles** ✓

**8.** (4 points)
Slope of AB = (1-0)/(5-0) = 1/5
Slope of DC = (5-4)/(7-2) = 1/5
**AB ∥ DC** ✓

Slope of AD = (4-0)/(2-0) = 2
Slope of BC = (5-1)/(7-5) = 4/2 = 2
**AD ∥ BC** ✓

Since both pairs of opposite sides are parallel, **ABCD is a parallelogram** ✓

**9.** (4 points)
a) Slope of PQ = (0-0)/(6-0) = 0 (horizontal)
   Slope of PR = (8-0)/(0-0) = undefined (vertical)
   Horizontal and vertical lines are perpendicular → **∠P = 90°**
   **△PQR is a right triangle** ✓

b) PQ = 6, PR = 8
   QR = √[(0-6)² + (8-0)²] = √[36+64] = √100 = 10
   Check: PQ² + PR² = 36 + 64 = 100 = QR²
   **Pythagorean Theorem satisfied → right triangle** ✓
