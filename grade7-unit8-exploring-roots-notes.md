## Lesson 1: Understanding Square Roots

### What is a Square Root?

**Square root** of a number is a value that, when multiplied by itself, gives that number.

**Symbol:** √ (radical sign)

**Definition:** If a² = b, then √b = a

**Example:**
```
Since 5 × 5 = 25
√25 = 5
```

### Perfect Squares

**Perfect squares** are numbers that have whole number square roots.

**First 15 perfect squares:**
```
1² = 1       √1 = 1
2² = 4       √4 = 2
3² = 9       √9 = 3
4² = 16      √16 = 4
5² = 25      √25 = 5
6² = 36      √36 = 6
7² = 49      √49 = 7
8² = 64      √64 = 8
9² = 81      √81 = 9
10² = 100    √100 = 10
11² = 121    √121 = 11
12² = 144    √144 = 12
13² = 169    √169 = 13
14² = 196    √196 = 14
15² = 225    √225 = 15
```

**Important:** Memorize these!

### Examples

**Example 1:** √36
```
6 × 6 = 36
√36 = 6
```

**Example 2:** √81
```
9 × 9 = 81
√81 = 9
```

**Example 3:** √144
```
12 × 12 = 144
√144 = 12
```

## Lesson 2: Principal vs. Negative Square Roots

### Two Square Roots

Every positive number has TWO square roots: one positive, one negative.

**Example:** For 25
```
5 × 5 = 25
(-5) × (-5) = 25
Both 5 and -5 are square roots of 25
```

### Principal Square Root

**The symbol √ means the POSITIVE (principal) square root only**

**Examples:**
```
√36 = 6 (not -6)
√49 = 7 (not -7)
√100 = 10 (not -10)
```

**To indicate negative square root:** Use -√
```
-√36 = -6
-√49 = -7
-√100 = -10
```

**Both square roots:** Use ±√
```
±√36 = 6 or -6
±√49 = 7 or -7
```

## Lesson 3: Estimating Square Roots

### Non-Perfect Squares

**Most numbers are NOT perfect squares**, so their square roots are not whole numbers.

**Strategy:** Find the two perfect squares the number is between.

**Example 1:** Estimate √50
```
√49 = 7 and √64 = 8
50 is between 49 and 64
So √50 is between 7 and 8

50 is closer to 49, so √50 ≈ 7.1
(Calculator: √50 ≈ 7.07)
```

**Example 2:** Estimate √20
```
√16 = 4 and √25 = 5
20 is between 16 and 25
So √20 is between 4 and 5

20 is closer to 16, so √20 ≈ 4.5
(Calculator: √20 ≈ 4.47)
```

**Example 3:** Estimate √75
```
√64 = 8 and √81 = 9
75 is between 64 and 81
So √75 is between 8 and 9

75 is closer to 81, so √75 ≈ 8.7
(Calculator: √75 ≈ 8.66)
```

## Lesson 4: Rational and Irrational Numbers

### Rational Numbers

**Rational numbers** can be expressed as a fraction a/b where a and b are integers and b ≠ 0.

**Examples of rational numbers:**
- Integers: 5, -3, 0
- Fractions: 1/2, 3/4, -5/8
- Terminating decimals: 0.5, 2.75
- Repeating decimals: 0.333..., 0.666...
- Perfect square roots: √4 = 2, √9 = 3

### Irrational Numbers

**Irrational numbers** CANNOT be expressed as a simple fraction.
- Their decimal form never ends and never repeats
- They go on forever without a pattern

**Examples of irrational numbers:**
- π (pi) ≈ 3.14159265...
- √2 ≈ 1.41421356...
- √3 ≈ 1.73205080...
- √5 ≈ 2.23606797...

**Key Concept:** Square roots of non-perfect squares are irrational!

### Identifying Rational vs. Irrational

**Rational:**
- √16 (equals 4)
- √25 (equals 5)
- 0.75 (equals 3/4)
- 2.333... (repeating)

**Irrational:**
- √10
- √7
- √50
- π

## Lesson 5: Simplifying Square Roots

### Perfect Square Factors

**Strategy:** Look for perfect square factors

**Rule:** √(a × b) = √a × √b

**Example 1:** Simplify √12
```
12 = 4 × 3
√12 = √(4 × 3)
√12 = √4 × √3
√12 = 2√3
```

**Example 2:** Simplify √18
```
18 = 9 × 2
√18 = √(9 × 2)
√18 = √9 × √2
√18 = 3√2
```

**Example 3:** Simplify √50
```
50 = 25 × 2
√50 = √(25 × 2)
√50 = √25 × √2
√50 = 5√2
```

**Example 4:** Simplify √72
```
72 = 36 × 2
√72 = √(36 × 2)
√72 = √36 × √2
√72 = 6√2
```

**Tip:** Look for the largest perfect square factor!

## Lesson 6: Operations with Square Roots

### Adding and Subtracting

**Rule:** You can only add/subtract like radicals (same number under the radical)

**Example 1:** 3√5 + 2√5
```
Like radicals (both √5)
3√5 + 2√5 = 5√5
```

**Example 2:** 7√3 - 4√3
```
Like radicals (both √3)
7√3 - 4√3 = 3√3
```

**Example 3:** 2√7 + 3√2
```
NOT like radicals
Cannot combine
Answer: 2√7 + 3√2
```

**Example 4:** √12 + √27
```
Simplify first:
√12 = 2√3
√27 = 3√3
Now combine: 2√3 + 3√3 = 5√3
```

### Multiplying

**Rule:** √a × √b = √(a × b)

**Example 1:** √2 × √8
```
√2 × √8 = √(2 × 8) = √16 = 4
```

**Example 2:** √3 × √12
```
√3 × √12 = √(3 × 12) = √36 = 6
```

**Example 3:** 2√3 × 5√2
```
2 × 5 = 10
√3 × √2 = √6
Answer: 10√6
```

## Lesson 7: Cube Roots

### What is a Cube Root?

**Cube root** of a number is a value that, when cubed (multiplied by itself three times), gives that number.

**Symbol:** ∛ (cube root sign)

**Definition:** If a³ = b, then ∛b = a

**Example:**
```
Since 4 × 4 × 4 = 64
∛64 = 4
```

### Perfect Cubes

**Perfect cubes** are numbers that have whole number cube roots.

**Common perfect cubes:**
```
1³ = 1        ∛1 = 1
2³ = 8        ∛8 = 2
3³ = 27       ∛27 = 3
4³ = 64       ∛64 = 4
5³ = 125      ∛125 = 5
6³ = 216      ∛216 = 6
7³ = 343      ∛343 = 7
8³ = 512      ∛512 = 8
9³ = 729      ∛729 = 9
10³ = 1000    ∛1000 = 10
```

### Negative Cube Roots

**Unlike square roots, cube roots CAN be negative!**

**Example:**
```
(-3) × (-3) × (-3) = -27
∛(-27) = -3
```

**More examples:**
```
∛(-8) = -2
∛(-125) = -5
∛(-1) = -1
```

## Lesson 8: Solving Equations with Squares

### Equations of the form x² = a

**To solve:** Take the square root of both sides
**Remember:** Consider both positive and negative roots!

**Example 1:** x² = 36
```
x = ±√36
x = ±6
Solutions: x = 6 or x = -6
```

**Example 2:** x² = 49
```
x = ±√49
x = ±7
Solutions: x = 7 or x = -7
```

**Example 3:** x² = 100
```
x = ±√100
x = ±10
Solutions: x = 10 or x = -10
```

**Example 4:** x² + 5 = 54
```
x² = 49
x = ±7
Solutions: x = 7 or x = -7
```

## Lesson 9: Solving Equations with Cubes

### Equations of the form x³ = a

**To solve:** Take the cube root of both sides
**Note:** Cube roots have only ONE solution

**Example 1:** x³ = 8
```
x = ∛8
x = 2
```

**Example 2:** x³ = 125
```
x = ∛125
x = 5
```

**Example 3:** x³ = -27
```
x = ∛(-27)
x = -3
```

**Example 4:** x³ - 10 = 54
```
x³ = 64
x = ∛64
x = 4
```

## Lesson 10: Real-World Applications

### Area Problems

**Example:** A square has area 144 cm². Find the side length.
```
Area = s²
144 = s²
s = √144
s = 12 cm
```

### Volume Problems

**Example:** A cube has volume 216 cm³. Find the edge length.
```
Volume = s³
216 = s³
s = ∛216
s = 6 cm
```

### Pythagorean Theorem Applications

**Example:** Find the hypotenuse
```
Legs: a = 6, b = 8
a² + b² = c²
36 + 64 = c²
100 = c²
c = √100
c = 10
```

### Distance Problems

**Example:** Free-fall distance
```
Formula: d = 16t²
If d = 256 feet, find t
256 = 16t²
16 = t²
t = 4 seconds
```

## Lesson 11: Comparing and Ordering with Roots

### Comparing Square Roots

**Strategy:** Compare the numbers under the radical, OR estimate the values

**Example 1:** Compare √50 and √48
```
50 > 48, so √50 > √48
```

**Example 2:** Compare √20 and 4.5
```
√16 = 4 and √25 = 5
√20 is between 4 and 5, approximately 4.47
√20 < 4.5
```

**Example 3:** Order from least to greatest: √10, 3, √8, 2.5
```
√8 ≈ 2.83
√10 ≈ 3.16
Order: 2.5, √8, 3, √10
```

## Lesson 12: Number Sets

### The Number System Hierarchy

**Natural Numbers (ℕ):** {1, 2, 3, 4, ...}

**Whole Numbers (W):** {0, 1, 2, 3, 4, ...}

**Integers (ℤ):** {..., -3, -2, -1, 0, 1, 2, 3, ...}

**Rational Numbers (ℚ):** All numbers that can be expressed as a/b

**Irrational Numbers:** Numbers that cannot be expressed as fractions

**Real Numbers (ℝ):** All rational and irrational numbers combined

### Classifying Numbers

**Example 1:** Classify √16
```
√16 = 4
Natural, Whole, Integer, Rational, Real
```

**Example 2:** Classify √7
```
Not a perfect square
Irrational, Real
```

**Example 3:** Classify -5
```
Integer, Rational, Real (NOT Natural or Whole)
```

## Key Vocabulary

- **Square Root:** A number that when multiplied by itself equals the given number
- **Cube Root:** A number that when cubed equals the given number
- **Perfect Square:** A number with a whole number square root
- **Perfect Cube:** A number with a whole number cube root
- **Principal Square Root:** The positive square root (√)
- **Radical:** The symbol √ or ∛
- **Radicand:** The number under the radical sign
- **Rational Number:** A number that can be expressed as a fraction
- **Irrational Number:** A number that cannot be expressed as a fraction
- **Real Numbers:** All rational and irrational numbers

## Practice Tips

1. Memorize perfect squares 1-15
2. Memorize perfect cubes 1-10
3. To estimate √n, find which perfect squares it's between
4. Square roots of non-perfect squares are irrational
5. √ always means the positive root
6. Cube roots can be negative
7. Simplify radicals by factoring out perfect squares
8. Only combine like radicals when adding/subtracting
9. When solving x² = a, remember ±√a
10. Check your solutions by squaring or cubing them
