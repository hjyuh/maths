### BONUS Section

**BONUS 1:**
Consider a right triangle with legs a and b and hypotenuse c.

sin(θ) = a/c
cos(θ) = b/c

sin²(θ) + cos²(θ) = (a/c)² + (b/c)²
                   = a²/c² + b²/c²
                   = (a² + b²)/c²

By Pythagorean Theorem: a² + b² = c²

Therefore: (a² + b²)/c² = c²/c² = 1

**Thus: sin²(θ) + cos²(θ) = 1** ✓

**BONUS 2:**
If tan(θ) = 2, then opposite/adjacent = 2/1

Draw a right triangle with opposite = 2, adjacent = 1
Using Pythagorean Theorem:
hypotenuse² = 2² + 1² = 4 + 1 = 5
hypotenuse = √5

Therefore: sin(θ) = opposite/hypotenuse = **2/√5 = 2√5/5**
