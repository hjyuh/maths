## Day 1 Practice: Triangle Congruence Definition & CPCTC

### Problems (10 problems)

**1.** Given △ABC ≅ △DEF, list all six pairs of corresponding congruent parts.

   a) ∠Q ≅ ___
   b) PR ≅ ___
   c) ∠Z ≅ ___
   d) XY ≅ ___

**3.** Given △ABC ≅ △RST, m∠A = 45°, m∠B = 65°, and BC = 12. Find:
   a) m∠R
   b) m∠S
   c) ST

**4.** True or False: If △ABC ≅ △DEF, then △CAB ≅ △FDE. Explain your reasoning.

**5.** Given: △ABC ≅ △DEF, AB = 3x + 5, and DE = 5x - 3. Find x and the length of AB.

**6.** Which sequence of rigid motions would map △ABC onto △DEF if A(0, 0), B(4, 0), C(2, 3) and D(0, 0), E(-4, 0), F(-2, 3)?

   - If PQ = 8, QR = 10, and PR = 12

**8.** If △ABC ≅ △XYZ, m∠A = 2x + 10, and m∠X = 3x - 20, find:
   a) The value of x
   b) m∠A

**9.** Given: △ABC ≅ △DEF
    Prove: AC ≅ DF
    Write a simple two-column proof.

**10.** A triangle has vertices A(1, 2), B(5, 2), C(3, 6). After a reflection over the y-axis, the image is △A'B'C'. Are △ABC and △A'B'C' congruent? Explain using the definition of congruence.

# Solutions

## Day 1 Solutions

**1.** Six pairs of corresponding congruent parts:
- ∠A ≅ ∠D
- ∠B ≅ ∠E
- ∠C ≅ ∠F
- AB ≅ DE
- BC ≅ EF
- AC ≅ DF

**2.**
a) ∠Q ≅ **∠Y**
b) PR ≅ **XZ**
c) ∠Z ≅ **∠R**
d) XY ≅ **PQ**

**3.**
a) m∠R = m∠A = **45°**
b) m∠S = m∠B = **65°**
c) ST = BC = **12**

**4.** **True.** If △ABC ≅ △DEF, then the correspondence is A↔D, B↔E, C↔F. Writing △CAB ≅ △FDE creates the correspondence C↔F, A↔D, B↔E, which is the same set of correspondences, just written in different order. The triangles are still congruent.

**5.**
AB ≅ DE (CPCTC)
3x + 5 = 5x - 3
8 = 2x
**x = 4**

AB = 3(4) + 5 = **17**

**6.** **Reflection over the y-axis.** Point B(4, 0) maps to E(-4, 0), C(2, 3) maps to F(-2, 3), and A stays at the origin.

**7.** Since △PQR ≅ △STU, all corresponding sides are congruent.
Perimeter of △STU = ST + TU + SU = PQ + QR + PR = 8 + 10 + 12 = **30**

**8.**
a) ∠A ≅ ∠X (CPCTC)
   2x + 10 = 3x - 20
   30 = x
   **x = 30**

b) m∠A = 2(30) + 10 = **70°**

**9.**
| Statement | Reason |
|-----------|--------|
| △ABC ≅ △DEF | Given |
| AC ≅ DF | CPCTC ✓ |

**10.** **Yes, they are congruent.** Reflection is a rigid motion, which preserves distance and angle measure. By the definition of congruence in terms of rigid motions, if one triangle can be mapped onto another using rigid motions, the triangles are congruent.

## Day 2 Solutions

**1.** **Yes, △ABC ≅ △DEF by SSS.** All three pairs of corresponding sides are congruent.

**2.** **Yes, △PQR ≅ △STU by SAS.** Two sides and the included angle are congruent.

**3.**
| Statement | Reason |
|-----------|--------|
| AB ≅ CD | Given |
| BC ≅ DA | Given |
| AC ≅ AC | Reflexive Property |
| △ABC ≅ △CDA | SSS ✓ |

**4.** SSA doesn't guarantee congruence because two sides and a non-included angle can create **two different triangles** (the ambiguous case). The side opposite the given angle can "swing" to create two possible triangle configurations.

**5.** **Yes, △ABC ≅ △XYZ by SAS.** AB ≅ XY, ∠B ≅ ∠Y (the included angle), and BC ≅ YZ.

**6.**
| Statement | Reason |
|-----------|--------|
| AB ≅ CD | Given |
| AD ≅ CB | Given |
| BD ≅ BD | Reflexive Property |
| △ABD ≅ △CDB | SSS ✓ |

**7.** For SSS congruence:
AB ≅ DE and AC ≅ DF

2x + 3 = 4x - 10
13 = 2x
**x = 6.5** (from first equation)

Check with second equation:
3x - 4 = x + 8
2x = 12
**x = 6**

For both equations to be satisfied, we need to check if there's a consistent value. Setting both:
If x = 6: AB = 2(6) + 3 = 15, AC = 3(6) - 4 = 14
If x = 6: DE = 4(6) - 10 = 14, DF = 6 + 8 = 14

This doesn't work perfectly. Let me reconsider: if AB ≅ DE and AC ≅ DF:
2x + 3 = 4x - 10 → x = 6.5
3x - 4 = x + 8 → x = 6

These give different values, suggesting the problem as stated may not have a consistent solution. However, if we consider AB ≅ DF and AC ≅ DE:
2x + 3 = x + 8 → **x = 5**
3x - 4 = 4x - 10 → **x = 6**

Still inconsistent. The problem may need revision, or there's no value of x that makes both conditions true simultaneously.

**8.**
AB = √[(3-0)² + (0-0)²] = 3
BC = √[(0-3)² + (4-0)²] = √(9+16) = 5
AC = √[(0-0)² + (4-0)²] = 4

DE = √[(8-5)² + (0-0)²] = 3
EF = √[(5-8)² + (4-0)²] = √(9+16) = 5
DF = √[(5-5)² + (4-0)²] = 4

Since AB = DE = 3, BC = EF = 5, AC = DF = 4, **△ABC ≅ △DEF by SSS** ✓

**9.** **Yes, by SAS.**
| Statement | Reason |
|-----------|--------|
| AB ≅ AC | Given |
| AD bisects ∠A | Given |
| ∠BAD ≅ ∠CAD | Definition of angle bisector |
| AD ≅ AD | Reflexive Property |
| △ABD ≅ △ACD | SAS ✓ |

**10.**
| Statement | Reason |
|-----------|--------|
| ABCD is a rectangle | Given |
| AB ≅ CD | Opposite sides of rectangle |
| ∠ABE ≅ ∠CDE | Alternate interior angles (AB ∥ CD) |
| BE ≅ DE | Diagonals of rectangle bisect each other |
| △ABE ≅ △CDE | SAS ✓ |

**9.**
