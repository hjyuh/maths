## Lesson 1: Properties of Operations

### The Commutative Property

**Addition:** a + b = b + a
**Multiplication:** a × b = b × a

**Examples:**
```
5 + 3 = 3 + 5 = 8
7 × 2 = 2 × 7 = 14

x + 4 = 4 + x
3y = y × 3
```

**Note:** Subtraction and division are NOT commutative!

### The Associative Property

**Addition:** (a + b) + c = a + (b + c)
**Multiplication:** (a × b) × c = a × (b × c)

**Examples:**
```
(2 + 3) + 4 = 2 + (3 + 4)
5 + 4 = 2 + 7
9 = 9 ✓

(2 × 3) × 4 = 2 × (3 × 4)
6 × 4 = 2 × 12
24 = 24 ✓
```

### The Distributive Property

**Formula:** a(b + c) = ab + ac

This property connects multiplication and addition.

**Example 1:** Expand using distributive property
```
3(x + 5) = 3x + 15
4(2y + 3) = 8y + 12
5(a - 2) = 5a - 10
```

**Example 2:** Factor using distributive property
```
6x + 9 = 3(2x + 3)
10y - 15 = 5(2y - 3)
```

## Lesson 2: Combining Like Terms

### What are Like Terms?

**Like terms** have the same variable raised to the same power.

**Like Terms:**
- 3x and 5x (both have x)
- 2y² and 7y² (both have y²)
- 4 and 9 (both are constants)

**NOT Like Terms:**
- 3x and 3y (different variables)
- 2x and 2x² (different exponents)
- 5x and 5 (one has a variable, one doesn't)

### Combining Like Terms

**Rule:** Add or subtract the coefficients, keep the variable the same.

**Example 3:** Simplify by combining like terms
```
3x + 5x = 8x
7y - 2y = 5y
4a + 3b + 2a = 6a + 3b
5x + 3 - 2x + 7 = 3x + 10
```

**Example 4:** Simplify more complex expressions
```
2(x + 3) + 4x
= 2x + 6 + 4x    (distribute first)
= 6x + 6         (combine like terms)

3(2y - 1) + 2(y + 4)
= 6y - 3 + 2y + 8    (distribute)
= 8y + 5             (combine like terms)
```

## Lesson 3: Generating Equivalent Expressions

### What are Equivalent Expressions?

Expressions that have the same value for all values of the variable.

**Example 5:** Show that expressions are equivalent
```
3(x + 2) and 3x + 6 are equivalent

When x = 4:
3(4 + 2) = 3(6) = 18
3(4) + 6 = 12 + 6 = 18 ✓

They give the same result for any value of x!
```

### Methods to Create Equivalent Expressions

**Method 1: Distribute**
```
4(x + 3) = 4x + 12
```

**Method 2: Factor**
```
6x + 9 = 3(2x + 3)
```

**Method 3: Combine like terms**
```
5x + 2x - 3 = 7x - 3
```

**Example 6:** Write three equivalent expressions for 2(x + 4) + 3x
```
Original: 2(x + 4) + 3x

Version 1: 2x + 8 + 3x (distribute)
Version 2: 5x + 8 (combine like terms)
Version 3: x(5) + 8 (factor out from variable)
```

## Lesson 4: Identifying Equivalent Expressions

### Strategy: Simplify Both Expressions

**Example 7:** Are 3(x + 2) and 3x + 2 equivalent?
```
3(x + 2) = 3x + 6
3x + 2 = 3x + 2

NO, they are not equivalent (3x + 6 ≠ 3x + 2)
```

**Example 8:** Are 2(3x + 1) and 6x + 2 equivalent?
```
2(3x + 1) = 6x + 2
6x + 2 = 6x + 2

YES, they are equivalent! ✓
```

### Strategy: Test with Values

**Example 9:** Are 4x + 2x and 6x equivalent?
```
Test with x = 3:
4(3) + 2(3) = 12 + 6 = 18
6(3) = 18

Test with x = 5:
4(5) + 2(5) = 20 + 10 = 30
6(5) = 30

YES, they appear equivalent (and they are!)
```

**Important:** Testing proves expressions are NOT equivalent if you find a value that gives different results, but it doesn't prove they ARE equivalent. You need to test multiple values or simplify algebraically.

## Lesson 5: Introduction to Equations

### What is an Equation?

An **equation** is a mathematical statement that two expressions are equal.

**Parts of an Equation:**
- Left side = Right side
- The **=** sign separates the two sides

**Examples:**
```
x + 5 = 12
3y = 15
2a - 3 = 7
```

### Solutions to Equations

A **solution** is a value that makes the equation true.

**Example 10:** Is x = 7 a solution to x + 5 = 12?
```
Substitute x = 7:
7 + 5 = 12
12 = 12 ✓

Yes, x = 7 is the solution!
```

**Example 11:** Is y = 3 a solution to 2y + 1 = 10?
```
Substitute y = 3:
2(3) + 1 = 10
6 + 1 = 10
7 = 10 ✗

No, y = 3 is NOT a solution.
```

## Lesson 6: Solving One-Step Addition and Subtraction Equations

### Addition Equations

**Strategy:** Use the inverse operation (subtraction)

**Example 12:** Solve x + 8 = 15
```
x + 8 = 15
x + 8 - 8 = 15 - 8    (subtract 8 from both sides)
x = 7

Check: 7 + 8 = 15 ✓
```

### Subtraction Equations

**Strategy:** Use the inverse operation (addition)

**Example 13:** Solve y - 6 = 10
```
y - 6 = 10
y - 6 + 6 = 10 + 6    (add 6 to both sides)
y = 16

Check: 16 - 6 = 10 ✓
```

**Example 14:** Solve n - 12 = 5
```
n - 12 = 5
n - 12 + 12 = 5 + 12
n = 17

Check: 17 - 12 = 5 ✓
```

## Lesson 7: Solving One-Step Multiplication and Division Equations

### Multiplication Equations

**Strategy:** Use the inverse operation (division)

**Example 15:** Solve 5x = 30
```
5x = 30
5x ÷ 5 = 30 ÷ 5    (divide both sides by 5)
x = 6

Check: 5(6) = 30 ✓
```

**Example 16:** Solve 3y = 27
```
3y = 27
y = 27 ÷ 3
y = 9

Check: 3(9) = 27 ✓
```

### Division Equations

**Strategy:** Use the inverse operation (multiplication)

**Example 17:** Solve x/4 = 7
```
x/4 = 7
x/4 × 4 = 7 × 4    (multiply both sides by 4)
x = 28

Check: 28/4 = 7 ✓
```

**Example 18:** Solve a/6 = 5
```
a/6 = 5
a = 5 × 6
a = 30

Check: 30/6 = 5 ✓
```

## Lesson 8: Writing Equations from Word Problems

### Identifying Key Information

**Look for:**
- What are you trying to find? (This is your variable)
- What operation is described?
- What is the relationship between quantities?

### Common Keywords

| Operation | Keywords |
|-----------|----------|
| Addition | sum, total, more than, increased by, plus |
| Subtraction | difference, less than, decreased by, minus, fewer |
| Multiplication | product, times, of, multiplied by |
| Division | quotient, divided by, per, out of |
| Equals | is, equals, results in, gives |

### Writing Equations

**Example 19:** Five more than a number is 18. Find the number.
```
Let x = the number
x + 5 = 18
x = 13
```

**Example 20:** Three times a number is 24. Find the number.
```
Let n = the number
3n = 24
n = 8
```

**Example 21:** A number divided by 4 equals 9. Find the number.
```
Let y = the number
y/4 = 9
y = 36
```

**Example 22:** Eight less than a number is 15. Find the number.
```
Let a = the number
a - 8 = 15
a = 23
```

## Lesson 9: Real-World Equation Problems

### Money Problems

**Example 23:** Sarah has $8. She buys a book and has $3 left. How much did the book cost?
```
Let b = cost of book
8 - b = 3
b = 5

The book cost $5.
```

### Age Problems

**Example 24:** Maria's age plus 7 equals 19. How old is Maria?
```
Let m = Maria's age
m + 7 = 19
m = 12

Maria is 12 years old.
```

### Geometry Problems

**Example 25:** The perimeter of a square is 48 cm. What is the length of one side?
```
Let s = side length
4s = 48    (perimeter of square = 4 × side)
s = 12

Each side is 12 cm.
```

### Rate Problems

**Example 26:** A car travels at a constant speed. In 3 hours, it travels 180 miles. What is the speed?
```
Let r = rate (speed)
3r = 180
r = 60

The car travels at 60 mph.
```

## Lesson 10: Solving Equations with Variables on Both Sides (Introduction)

### Simple Cases

**Example 27:** Solve 5x = 3x + 10
```
5x = 3x + 10
5x - 3x = 3x + 10 - 3x    (subtract 3x from both sides)
2x = 10
x = 5

Check: 5(5) = 3(5) + 10
       25 = 15 + 10
       25 = 25 ✓
```

**Example 28:** Solve 7y - 2y = 20
```
7y - 2y = 20
5y = 20
y = 4

Check: 7(4) - 2(4) = 20
       28 - 8 = 20
       20 = 20 ✓
```

## Key Vocabulary

- **Coefficient:** The number in front of a variable
- **Constant:** A number without a variable
- **Term:** A part of an expression (number, variable, or both)
- **Like Terms:** Terms with the same variable and exponent
- **Equivalent Expressions:** Expressions that have the same value for all variable values
- **Equation:** A statement that two expressions are equal
- **Solution:** A value that makes an equation true
- **Inverse Operation:** The opposite operation (addition ↔ subtraction, multiplication ↔ division)
- **Distributive Property:** a(b + c) = ab + ac
- **Commutative Property:** a + b = b + a; a × b = b × a
- **Associative Property:** (a + b) + c = a + (b + c)

## Practice Tips

1. **Always simplify expressions** before determining if they're equivalent
2. **Distribute first**, then combine like terms
3. **Check your solutions** by substituting back into the original equation
4. **Use inverse operations** to solve equations
5. **Keep equations balanced** - what you do to one side, do to the other
6. **Look for keywords** in word problems to determine the operation
7. **Define your variable** before writing an equation
8. **Show all steps** in your work

---

## Common Mistakes to Avoid

1. **Not distributing to all terms**
   - Incorrect: 3(x + 2) = 3x + 2
   - Correct: 3(x + 2) = 3x + 6

2. **Combining unlike terms**
   - Incorrect: 3x + 4y = 7xy
   - Correct: 3x + 4y (cannot be simplified)

3. **Forgetting to use the same operation on both sides**
   - Must maintain balance in equations

4. **Mixing up "less than" in word problems**
   - "5 less than x" is x - 5, not 5 - x

5. **Not checking solutions**
   - Always substitute your answer back to verify

6. **Dropping the negative sign**
   - Be careful with subtraction: 5 - 2x ≠ 5 + 2x
