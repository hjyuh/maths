## Part 3: Quadratic Models

**11.**

a) **h(t) = -16t² + 40t + 8**

b) **Maximum height = 33 feet**

Solution:
```
Vertex at t = -40/(2·(-16)) = 40/32 = 1.25 seconds

h(1.25) = -16(1.5625) + 50 + 8
        = -25 + 50 + 8
        = 33 feet
```

**12.** 6 seconds

Solution:
```
Set h(t) = 0:
-16t² + 96t = 0
-16t(t - 6) = 0
t = 0 (launch) or t = 6 (landing)

In air for 6 seconds
```

## Part 4: Exponential Models

**13.**

a) **P(t) = 1200(1.04)^t**

b) **≈ 1776 people**

Solution:
```
P(10) = 1200(1.04)^10
      ≈ 1200(1.480)
      ≈ 1776
```

**14.** ≈ $9,956.10

Solution:
```
V(t) = 22000(1 - 0.18)^t
     = 22000(0.82)^t

V(4) = 22000(0.82)^4
     ≈ 22000(0.4526)
     ≈ 9956.10
```

**15.** Model: A = 3000e^(0.05t); Time ≈ 5.75 years

Solution:
```
4000 = 3000e^(0.05t)
4/3 = e^(0.05t)
ln(4/3) = 0.05t
t = ln(4/3)/0.05
t ≈ 0.2877/0.05
t ≈ 5.75 years
```

**18.** Average rate = 3

**20.**

a) **Cost: C(x) = 12000 + 8x**
   **Revenue: R(x) = 25x**

b) **Break-even at 706 calculators** (or ≈ 705.88, round up to 706)


## BONUS Section

**BONUS:** Width = 50 ft, Length = 100 ft, Area = 5000 sq ft

Solution:
```
Let x = width (perpendicular to river)
Then length = 200 - 2x (parallel to river)

Area: A(x) = x(200 - 2x)
      A(x) = 200x - 2x²
      A(x) = -2x² + 200x

Maximum at vertex:
x = -200/(2·(-2)) = 200/4 = 50

Width = 50 feet
Length = 200 - 2(50) = 100 feet
Maximum area = 50 × 100 = 5000 square feet
```
