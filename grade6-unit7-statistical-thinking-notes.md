## Lesson 1: Statistical Questions

### What is a Statistical Question?

A **statistical question** is one that anticipates variability in the data and requires collecting data to answer.

**Key Concept:** Statistical questions have answers that vary, not just one answer.

### Examples of Statistical Questions

**Statistical Questions (answers vary):**
- How tall are the students in our class?
- What are the favorite colors of students in grade 6?
- How many hours per week do students exercise?

**NOT Statistical Questions (one answer):**
- How tall is Maria?
- What is your favorite color?
- How many hours did I exercise yesterday?

### Identifying Statistical Questions

**Example 1:**
```
Question: How many pets do students in our school have?
Statistical? YES - answers will vary from student to student

Question: How many pets does Sarah have?
Statistical? NO - there is only one specific answer
```

**Example 2:**
```
Question: What is the temperature today?
Statistical? NO - one specific answer for today

Question: What were the high temperatures this month?
Statistical? YES - temperatures varied from day to day
```

## Lesson 2: Data Distributions

### What is a Distribution?

A **distribution** shows how data values are spread out.

We can display distributions using:
- Dot plots
- Histograms
- Box plots
- Frequency tables

### Understanding Variability

**Variability** describes how spread out the data values are.

**Low variability:** Data points are close together
**High variability:** Data points are spread far apart

**Example 3:** Test scores
```
Class A: 85, 87, 86, 85, 88 (low variability - scores are close)
Class B: 65, 95, 72, 88, 80 (high variability - scores are spread out)
```

## Lesson 3: Measures of Center - Mean

### What is the Mean?

The **mean** (or average) is the sum of all values divided by the number of values.

**Formula:** Mean = (Sum of all values) ÷ (Number of values)

### Calculating the Mean

**Example 4:** Find the mean of: 8, 12, 15, 10, 5
```
Step 1: Add all values
8 + 12 + 15 + 10 + 5 = 50

Step 2: Divide by number of values
50 ÷ 5 = 10

Mean = 10
```

**Example 5:** Test scores: 85, 90, 78, 92, 85
```
Sum = 85 + 90 + 78 + 92 + 85 = 430
Number of scores = 5
Mean = 430 ÷ 5 = 86
```

### When to Use the Mean

The mean is useful when:
- You want to find a typical value
- The data doesn't have extreme outliers
- You need to represent all data values

**Note:** The mean is affected by outliers (extremely high or low values)

## Lesson 4: Measures of Center - Median

### What is the Median?

The **median** is the middle value when data is arranged in order.

### Finding the Median

**Step 1:** Arrange data in order from least to greatest
**Step 2:** Find the middle value

**Example 6:** Find the median of: 7, 3, 9, 5, 11
```
Step 1: Order: 3, 5, 7, 9, 11
Step 2: Middle value: 7

Median = 7
```

**Example 7:** Find the median of: 12, 8, 15, 10, 6, 14
```
Step 1: Order: 6, 8, 10, 12, 14, 15
Step 2: Two middle values: 10 and 12
Step 3: Average them: (10 + 12) ÷ 2 = 11

Median = 11
```

**Rule:**
- Odd number of values: median is the middle value
- Even number of values: median is the average of the two middle values

### When to Use the Median

The median is useful when:
- Data has outliers (extreme values)
- You want the middle value
- Data is skewed

**Example 8:** Salaries: $30,000, $32,000, $35,000, $38,000, $250,000
```
Mean = $77,000 (affected by the outlier $250,000)
Median = $35,000 (better represents typical salary)
```

## Lesson 5: Measures of Center - Mode

### What is the Mode?

The **mode** is the value that appears most frequently in a data set.

### Finding the Mode

**Example 9:** Find the mode: 5, 8, 3, 8, 9, 8, 6
```
8 appears 3 times (more than any other value)
Mode = 8
```

**Example 10:** Find the mode: 12, 15, 10, 12, 18, 15, 12, 15
```
Both 12 and 15 appear 3 times
Modes = 12 and 15 (bimodal - two modes)
```

**Special Cases:**
- **No mode:** All values appear the same number of times
- **Bimodal:** Two values appear most frequently
- **Multimodal:** More than two values appear most frequently

### When to Use the Mode

The mode is useful when:
- You want to know the most common value
- Working with categorical data (colors, brands, etc.)
- Data has clear clusters

## Lesson 6: Choosing the Best Measure of Center

### Comparing Mean, Median, and Mode

| Measure | Best Used When | Affected by Outliers? |
|---------|----------------|----------------------|
| Mean | Data is symmetric, no outliers | Yes |
| Median | Data has outliers or is skewed | No |
| Mode | Finding most common value | No |

**Example 11:** Which measure is best?
```
Quiz scores: 8, 9, 7, 10, 8, 9, 8, 0

Mean = 7.375 (affected by the 0)
Median = 8 (middle value)
Mode = 8 (appears most often)

Best measure: Median or Mode (the 0 is an outlier)
```

## Lesson 7: Range

### What is Range?

**Range** is the difference between the largest and smallest values.

**Formula:** Range = Maximum value − Minimum value

### Calculating Range

**Example 12:** Find the range: 15, 8, 22, 11, 19
```
Maximum = 22
Minimum = 8
Range = 22 - 8 = 14
```

**Example 13:** Temperatures: 65°F, 72°F, 58°F, 80°F, 68°F
```
Maximum = 80°F
Minimum = 58°F
Range = 80 - 58 = 22°F
```

### Interpreting Range

- **Large range:** High variability (data is spread out)
- **Small range:** Low variability (data is clustered together)

## Lesson 8: Interquartile Range (IQR)

### What is IQR?

The **Interquartile Range (IQR)** measures the spread of the middle 50% of data.

**IQR = Q3 - Q1**

Where:
- **Q1** (First Quartile): Median of the lower half
- **Q2** (Second Quartile): Median of all data
- **Q3** (Third Quartile): Median of the upper half

### Finding the IQR

**Example 14:** Find IQR for: 5, 7, 8, 10, 12, 14, 18, 20, 22
```
Step 1: Find median (Q2): 12

Step 2: Find Q1 (median of lower half: 5, 7, 8, 10)
Q1 = (7 + 8) ÷ 2 = 7.5

Step 3: Find Q3 (median of upper half: 14, 18, 20, 22)
Q3 = (18 + 20) ÷ 2 = 19

Step 4: Calculate IQR
IQR = Q3 - Q1 = 19 - 7.5 = 11.5
```

### Why Use IQR?

- **Not affected by outliers** (unlike range)
- Shows spread of middle 50% of data
- Useful for comparing distributions

## Lesson 9: Mean Absolute Deviation (MAD)

### What is MAD?

**Mean Absolute Deviation (MAD)** measures the average distance of each data point from the mean.

### Calculating MAD

**Steps:**
1. Find the mean
2. Find the distance of each value from the mean (absolute value)
3. Find the mean of those distances

**Example 15:** Find MAD for: 4, 6, 8, 10, 12
```
Step 1: Mean = (4 + 6 + 8 + 10 + 12) ÷ 5 = 8

Step 2: Find distances from mean:
|4 - 8| = 4
|6 - 8| = 2
|8 - 8| = 0
|10 - 8| = 2
|12 - 8| = 4

Step 3: MAD = (4 + 2 + 0 + 2 + 4) ÷ 5 = 12 ÷ 5 = 2.4
```

### Interpreting MAD

- **Small MAD:** Data values are close to the mean (low variability)
- **Large MAD:** Data values are spread out from the mean (high variability)

## Lesson 10: Displaying Data with Dot Plots

### What is a Dot Plot?

A **dot plot** shows each data value as a dot above a number line.

### Creating a Dot Plot

**Example 16:** Display this data: 5, 6, 5, 7, 8, 5, 6, 7, 5
```
Number of dots above each value:
5: ●●●●
6: ●●
7: ●●
8: ●

5   6   7   8
●   ●   ●   ●
●   ●   ●
●
●
```

### Reading a Dot Plot

From a dot plot, you can identify:
- Mode (tallest column)
- Range (spread from left to right)
- Clusters and gaps
- Overall shape of distribution

## Lesson 11: Displaying Data with Histograms

### What is a Histogram?

A **histogram** uses bars to show the frequency of data in intervals (bins).

**Key Differences from Bar Graph:**
- Bars touch each other
- Shows continuous data
- X-axis shows intervals, not categories

### Creating a Histogram

**Example 17:** Test scores: 65, 70, 75, 78, 82, 85, 88, 90, 92, 95
```
Intervals:  60-69  70-79  80-89  90-99
Frequency:    1      3      3      3

[Histogram would show bars of heights 1, 3, 3, 3]
```

## Lesson 12: Box Plots

### What is a Box Plot?

A **box plot** (box-and-whisker plot) displays the five-number summary:
1. Minimum
2. Q1 (First Quartile)
3. Median (Q2)
4. Q3 (Third Quartile)
5. Maximum

### Creating a Box Plot

**Example 18:** Create a box plot for: 5, 7, 8, 10, 12, 14, 18, 20, 22
```
Minimum = 5
Q1 = 7.5
Median = 12
Q3 = 19
Maximum = 22

[Box plot would show whisker from 5 to 7.5, box from 7.5 to 19 with line at 12, whisker from 19 to 22]
```

### Reading a Box Plot

- **Box:** Contains middle 50% of data (Q1 to Q3)
- **Line in box:** Shows median
- **Whiskers:** Show min to Q1 and Q3 to max
- **Length of box:** Shows IQR

## Lesson 13: Comparing Distributions

### Using Measures to Compare

When comparing two data sets, look at:
- **Centers:** Compare mean or median
- **Spread:** Compare range, IQR, or MAD
- **Shape:** Look at overall distribution

**Example 19:** Compare two classes' test scores
```
Class A: Mean = 85, MAD = 3
Class B: Mean = 85, MAD = 8

Conclusion: Same average score, but Class A has more consistent scores (less variability)
```

**Example 20:**
```
Store A temperatures: Median = 68°F, IQR = 4°F
Store B temperatures: Median = 68°F, IQR = 10°F

Conclusion: Both stores have the same typical temperature, but Store B has more variable temperatures
```

## Key Vocabulary

- **Statistical Question:** A question with varying answers requiring data collection
- **Distribution:** How data values are spread out
- **Mean:** The average of all values
- **Median:** The middle value when data is ordered
- **Mode:** The most frequently occurring value
- **Range:** Maximum value minus minimum value
- **Outlier:** A value much higher or lower than others
- **Quartile:** Values that divide data into four equal parts
- **IQR (Interquartile Range):** Q3 - Q1, spread of middle 50%
- **MAD (Mean Absolute Deviation):** Average distance from the mean
- **Dot Plot:** Shows each value as a dot on a number line
- **Histogram:** Uses bars to show frequency in intervals
- **Box Plot:** Shows five-number summary visually

## Practice Tips

1. **For mean:** Add all values, then divide by how many values
2. **For median:** Always put data in order first!
3. **For mode:** Count how many times each value appears
4. **For range:** Subtract smallest from largest
5. **For IQR:** Find Q1 and Q3, then subtract
6. **When comparing:** Look at both center AND spread
7. **Check your work:** Does your answer make sense?

---

## Common Mistakes to Avoid

1. **Not ordering data before finding median**
   - Always arrange data from least to greatest first

2. **Forgetting to divide when finding mean**
   - Mean = sum ÷ count, not just the sum

3. **Confusing mean and median**
   - Mean: average of all values
   - Median: middle value

4. **Saying there's always a mode**
   - Sometimes there is no mode (all values appear equally)

5. **Including median when finding quartiles**
   - For odd number of values, don't include the median in either half

6. **Not using absolute value for MAD**
   - Distances are always positive
