4. **D) (-∞, 0) and (0, ∞)**

   - f''(x) = 6x⁻⁴ > 0 for all x ≠ 0

6. **A) 1.5 m/s**

## Part 2: Short Answer

11. **Critical points and classification:**
    ```
    f(x) = x³ - 6x² + 9x + 2
    f'(x) = 3x² - 12x + 9 = 3(x² - 4x + 3) = 3(x - 1)(x - 3)

    Critical points: x = 1 and x = 3

    Test intervals:
    x < 1: f'(0) = 9 > 0 (increasing)
    1 < x < 3: f'(2) = -3 < 0 (decreasing)
    x > 3: f'(4) = 9 > 0 (increasing)

    x = 1: local maximum (+ to -)
    x = 3: local minimum (- to +)
    ```

12. **Absolute extrema:**
    ```
    g(x) = x³ - 3x
    g'(x) = 3x² - 3 = 3(x² - 1)
    Critical points: x = ±1

    Evaluate:
    g(-2) = -8 + 6 = -2
    g(-1) = -1 + 3 = 2
    g(1) = 1 - 3 = -2
    g(3) = 27 - 9 = 18

    Absolute maximum: g(3) = 18
    Absolute minimum: g(-2) = g(1) = -2
    ```

13. **Inflection points:**
    ```
    h(x) = x⁴ - 4x³
    h'(x) = 4x³ - 12x²
    h''(x) = 12x² - 24x = 12x(x - 2)

    Possible inflection points: x = 0, 2

    Test: x < 0: h''(-1) = 36 > 0
          0 < x < 2: h''(1) = -12 < 0
          x > 2: h''(3) = 36 > 0

    Both are inflection points:
    (0, 0) and (2, -16)
    ```

14. **Second derivative test:**
    ```
    f(x) = 2x³ - 9x² + 12x - 3
    f'(x) = 6x² - 18x + 12 = 6(x² - 3x + 2) = 6(x - 1)(x - 2)
    Critical points: x = 1, 2

    f''(x) = 12x - 18
    f''(1) = -6 < 0 → local maximum
    f''(2) = 6 > 0 → local minimum
    ```

15. **Linear approximation:**
    ```
    f(x) = ³√x = x^(1/3)
    f'(x) = (1/3)x^(-2/3)

    At x = 27:
    f(27) = 3
    f'(27) = 1/(3 · 9) = 1/27

    L(x) = 3 + (1/27)(x - 27)
    L(27.2) = 3 + (1/27)(0.2)
            = 3 + 0.2/27
            ≈ 3.0074
    ```

16. **Minimize perimeter:**
    ```
    Area: xy = 64, so y = 64/x
    Perimeter: P = 2x + 2y = 2x + 128/x

    P'(x) = 2 - 128/x² = 0
    2x² = 128
    x² = 64
    x = 8

    y = 64/8 = 8

    Dimensions: 8 cm × 8 cm (square)
    ```

17. **Related rates - circle area:**
    ```
    A = πr²
    dA/dt = 2πr(dr/dt)

    Given: dr/dt = 3 cm/s, r = 8 cm
    dA/dt = 2π(8)(3) = 48π cm²/s
    ```

18. **Related rates - ladder:**
    ```
    x² + y² = 169

    Given: dx/dt = 4 ft/s, x = 5
    Find: dy/dt

    y = √(169 - 25) = 12 ft

    2x(dx/dt) + 2y(dy/dt) = 0
    5(4) + 12(dy/dt) = 0
    dy/dt = -20/12 = -5/3 ft/s

    The top is sliding down at 5/3 ft/s
    ```

**b) Distance equation (3 points)**

**c) Rate of separation (5 points)**
```
Given: dx/dt = 60 mph, dy/dt = 50 mph

After 2 hours:
x = 60(2) = 120 miles
y = 50(2) = 100 miles
z = √(120² + 100²) = √24400 = 20√61 miles

Differentiate: 2z(dz/dt) = 2x(dx/dt) + 2y(dy/dt)
               z(dz/dt) = x(dx/dt) + y(dy/dt)

20√61(dz/dt) = 120(60) + 100(50)
20√61(dz/dt) = 7200 + 5000 = 12200

dz/dt = 12200/(20√61) = 610/√61 = 610√61/61 ≈ 78.1 mph
```
